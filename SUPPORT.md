# Pivot support

For ordinary installation, update and usage problems, open an issue in the
official public source repository, `QT7-C23/Pivot`, and include the Pivot version,
Windows version, expected behavior and sanitized reproduction steps.

Do not post provider API keys, GitHub tokens, signing material, private project
files or full logs containing prompts and paths. Security-sensitive reports
must follow `SECURITY.md` and use private vulnerability reporting.

The Marketplace catalog uses the separate `QT7-C23/Pivot-Marketplace`
repository. Catalog or package metadata problems belong there; desktop runtime
problems and signed desktop Releases belong in the `Pivot` source repository.
