# Pivot Beta-0.1.61 Dry-run Pivot failure handoff

Date: 2026-07-30  
Visible version: `Beta-0.1.61`  
Package/updater SemVer: `0.1.61-beta`

## Completed slice

- Added strict shared contracts for authoritative failure observation,
  immutable failure evidence and continuation-only handoffs.
- Added narrow Main Ports and durable WAL SQLite registries for failure
  evidence and `pending-guarded-review` handoffs.
- Added a narrow `AxisTaskExecutor` decorator that records authoritative
  Worker attempt completion/failure/cancellation before Pivot dispatch.
- Connected the existing registered Dry-run Main handler to failure
  observation only when its latest durable Run event is `task-failed`.
- Coalesced concurrent observations and reused durable decisions, dispatches
  and handoffs after duplicate delivery or restart.
- Kept terminal discard, escalation and stop results out of continuation
  handoffs.

## Invariants preserved

- Shared input contains only revision, Run and Session ownership; no caller
  supplies task, project root, write set, authority, proof or Receipt.
- Concrete registries and the filesystem remain Main-owned.
- Worker and Renderer receive no Admin Port, database handle, signing key,
  Fingerprint Port or filesystem capability.
- A continuation handoff is not execution authority. It cannot call Guarded
  Safe Write without a separately issued reviewed-proposal Receipt and exact
  reviewed writes.
- No new Pivot IPC, Preload contract or Renderer surface was added.

## Deliberately absent

- automatic reviewed-proposal generation or approval;
- Guarded continuation scheduling/execution;
- non-Dry-run production failure observation;

Add a Main-owned consumer for `pending-guarded-review` handoffs. It must obtain
