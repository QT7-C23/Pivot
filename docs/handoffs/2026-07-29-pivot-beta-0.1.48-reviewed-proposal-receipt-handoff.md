## Delivered engineering slice

Beta-0.1.48 binds the default-off model proposal and read-only Diff Review to later Guarded Safe Write submission with a short-lived Main-issued Receipt.

- Added strict shared Receipt and submission contracts with runtime validation.
- Added narrow Main issuer/verifier Ports and an HMAC-SHA-256 service.
- Bound proposal/project/run/session/task identity, authoritative Run revision, exact proposed-content SHA-256 and complete review-time Fingerprint state.
- Captured Fingerprints before the proposal model, cross-checked source Reader results and re-verified before issuance.
- Verified Receipt signature, expiry, ownership, revision, exact writes and current full baseline before Task claim.
- Rechecked the Receipt baseline against post-Lease Fingerprints before Checkpoint, closing the pre-claim-to-Lease race.
- Kept signing keys, Fingerprint Ports, Admin Ports, databases and raw filesystem capabilities out of Worker and Renderer.
- Locked Receipt-bound Renderer content; edits require proposal regeneration.

This is still a default-off explicit proposal/review/approval workflow, not autonomous execution or a complete end-user feature.

## Real failure paths

- Receipt tamper, expiry, ownership mismatch, stale revision and edited proposed content.
- Review baseline modified, deleted, created or replaced with the same content.
- Race after pre-claim verification and before/while Lease coordination.
- Registered Main-handler permission denial/timeout, Gate rollback, startup recovery and cleanup failure using a real model proposal and HMAC Receipt.
- Production-build Electron stale-review path: external edit after Diff Review is rejected before permission and Task claim; Run stays `planned`, Task stays `pending`, and external content remains.

The prior Electron proposal/review/permission/compile-Gate rollback path also passes.
