# Pivot Beta-1.6.0 Marketplace foundation handoff

Date: 2026-08-11  
Display version: `Beta-1.6.0`  
Package version: `1.6.0-beta`

## Delivered engineering slice

This slice establishes the reviewed bottom boundary required before the Figma
Marketplace Favorites screen can consume real data.

- `src/shared/marketplace-contracts.ts` strictly validates immutable Catalog
  Source, Entry, Snapshot, Ed25519 Signature, Favorite Collection and
  optimistic Favorite write values.
- Catalog entries are limited to free Plugins, Skills, Prompts and Themes.
  HTTPS endpoints, SHA-256 package identity, exact trusted key binding and a
  maximum seven-day snapshot lifetime are mandatory.
- Unknown fields, commerce data, insecure endpoints, malformed integrity
  evidence, duplicate resources and source/key mismatches fail closed.
- `MarketplaceCatalogReaderPort`, `MarketplaceFavoriteReaderPort` and
  `MarketplaceFavoriteWriterPort` are separate narrow capabilities.
- `SqliteMarketplaceFavoriteAdapter` owns the versioned database migration,
  atomic revision checks, idempotent add/remove behavior and restart recovery.
- Structural tests keep SQLite and the concrete Adapter out of Renderer and
  Worker code.

## Verification evidence

- Targeted Marketplace contract, boundary and real SQLite Adapter coverage:
  3 test files / 14 tests passed.
- Full Vitest regression: 242 test files / 870 tests passed.
- Strict TypeScript no-emit and the formal Electron build passed.
- Performance remained within the unchanged gate: 20 JavaScript chunks,
  largest worker 11.53 MiB, largest app 4.18 MiB, initial Renderer 1.74 MiB
  and total output 22.86 MiB.
- `better-sqlite3` native binding matches Electron.
- No installer or portable package was generated.

## Explicit limitations

- There is no configured production Catalog source or trusted public-key
  registry yet.
- There is no Marketplace IPC, Renderer service/store or Figma Favorites
  production wiring in this slice.
- There is no package download, signature verification implementation,
  staging, installation, activation, rollback, update or uninstall lifecycle.
- Figma example extensions, ratings, runs and download counts were not copied.
