# Pivot Beta-1.3.0 durable Attention lifecycle handoff

Date: 2026-08-03  
Display version: `Beta-1.3.0`  
Package version: `1.3.0-beta`

## Delivered engineering slice

This slice implements the local durable Attention evidence and lifecycle
foundation represented by Figma Additional Interfaces nodes `425:6216`,
`425:6244`, `425:6268`, `425:6287` and persistent panel node `74:1976`.

- `src/shared/attention.ts` owns strict version-1 observation, record, history
  and optimistic lifecycle contracts.
- Main consumers depend on `AttentionReaderPort`, `AttentionObservationPort`
  and `AttentionLifecyclePort`; only Main composition constructs
  `SqliteAttentionAdapter`.
- The SQLite Adapter performs a versioned migration, idempotent observation by
  `sourceId`, optimistic resolve/reopen transitions, restart recovery and
  fail-closed runtime validation of persisted rows.
- Strict IPC exposes only `attention:list`, `attention:observe`,
  `attention:resolve` and `attention:reopen`.
- Renderer validates every Main response and receives no database handle,
  filesystem capability, Admin Port or execution authority.
- Current runtime errors and `PermissionRequest` values are the only production
  observations. Figma demonstration incidents are not inserted.
- The queue renders real list, detail, resolved and reopened states. Permission
  review and runtime switching route to their existing application owners.

## Lifecycle behavior

1. A new `sourceId` creates an `open` record at revision 1.
2. Repeating an unchanged open observation is idempotent.
3. Changed evidence updates the existing record and increments revision.
4. Dismiss resolves with `expectedRevision` and records `resolvedAt`.
5. Explicit reopen increments revision and clears `resolvedAt`.
6. A later real observation of a resolved source automatically marks the same
   record `reopened` rather than creating a duplicate.
7. Stale revisions, malformed IPC, corrupt rows and unknown record IDs fail
   closed.

## Explicit non-delivery and next work

- Attention does not reconnect runtimes, decide permissions or execute recovery.
- Observation currently originates from the real Renderer aggregate error and
  permission-request projection. Main-owned ingestion for additional runtime,
  Axis, update and background subsystem evidence remains a future slice.
- Remote notification delivery and OS notification policy remain absent.
- Feedback remains a local outbox; remote delivery is not part of this slice.
- Marketplace discovery, plugin installation/execution, command-palette
  execution, profile editing, signed distribution, packaged E2E and real
  previous-version upgrade/rollback remain open product/release work.

The recommended next independent slice is a Main-owned Attention ingestion
Port for runtime and Axis failure evidence, with deduplication tests and no
Renderer authority expansion. Re-read the current Figma selection before
starting because the design file is actively changing.
