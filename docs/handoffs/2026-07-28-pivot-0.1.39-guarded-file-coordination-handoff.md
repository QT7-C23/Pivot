# Pivot 0.1.39 Guarded File Coordination 交接

## 本轮完成

完成内部 Guarded Safe Write 文件协调工程切片：

- Lease Task Coordinator 新增只读 `verifyAll`，原子校验所有权、active 状态和乐观 Version；
- safe-write Execution Authority 严格绑定 `projectId`、完整 Lease evidence 和 Fingerprint evidence；
- Authority 有效期不超过任一 Lease/Fingerprint evidence；
- `AxisGuardedSafeWriteHarness` 固定执行顺序：
  1. `acquireAll`；
  2. `captureAll`；
  3. create Checkpoints；
  4. issue signed Authority；
  5. verify Lease versions；
  6. verify fingerprints；
  7. start transaction and guarded writes；
- 外部修改、删除、创建或同内容替换在事务启动前以 `external-change` 阻断，不执行 Worker，也不使用旧 Checkpoint 覆盖外部改动；
- 完成、阻断、取消、Worker/Gate 失败和回滚均从统一 `finally` 尝试 `releaseAll`；
- Worker 仍只获得 Authority 与窄 writer，没有 Lease/Fingerprint Factory、Admin Port、数据库或原始文件系统能力。

## 模块边界

协调器只依赖：

- `AxisFileLeasePortFactory`；
- `AxisFileFingerprintPortFactory`；
- `AxisSafeWriteProjectBindingPort`；
- 已有 Permission、Checkpoint、Authority、Transaction、Rollback、Gate 与 Worker Ports。

具体 `SqliteAxisFileLeaseStore` 和 `AxisExternalFileFingerprintAdapter` 没有进入协调器依赖。Renderer/IPC 也没有新增相关能力。

## 测试先行与真实失败路径

先建立失败测试，再补实现。新增或加强的覆盖包括：

- 完整顺序断言；
- Authority 对 Lease/Fingerprint/project evidence 的严格绑定、签名与过期上限；
- Lease 批量只读验证不改变状态，旧 Version 失败；
- modified、deleted、created、replaced 四类真实文件变化；
- 外部变化时 zero writes、zero transaction、no rollback；
- Checkpoint、Authority、Worker、Gate、取消、完成各路径的 Lease 释放；
- Worker/Renderer 不可获得工厂、Admin、数据库或文件系统能力的结构测试。
