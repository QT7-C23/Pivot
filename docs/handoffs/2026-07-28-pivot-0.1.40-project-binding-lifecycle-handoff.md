# Pivot 0.1.40 Persistent Project Binding 与 Lease Lifecycle 交接

## 本轮完成

- 严格 Project Binding、Lease cleanup request/receipt 共享合同；
- `SqliteAxisProjectBindingStore` 按规范化项目根持久分配稳定 `projectId`；
- 同一项目跨 Session、跨进程重启保持同一 project identity；
- Session binding 不可静默改绑，失败时原记录不变；
- Reader Port 运行时只暴露 `findBySession`；
- File Identity、Fingerprint、Execution Authority 和内部 Guarded Safe Write 统一依赖 Reader Port；
- File Identity 显式拒绝 task `projectId` 与持久 Session binding 不一致；
- Lease Admin 新增 Session 级释放；
- `AxisRunLeaseLifecycleCoordinator` 只依赖 `releaseForRun/releaseForSession`，支持 Run/Session 终态清理、幂等 receipt 和真实 Adapter 失败传播；
- 统一 Lease `listOwn` 为稳定 file-key 顺序，消除临时路径哈希导致的测试偶发顺序差异。

## 边界

- Worker/Renderer 没有 Project Binding Writer/Admin、Lease Admin、数据库或文件系统能力；
- Shared 合同不依赖 Main/Renderer 或 Node 文件系统；
- SQLite Store 只由 Factory 提供冻结 Reader Port；
- 新 Store、Lifecycle Coordinator 当前只有底层测试调用者，尚未进入生产 composition root 或 IPC。

## 验证

- 122 个测试文件、488 项测试全部通过；
- TypeScript `tsc --noEmit` 通过；
- Electron production build 通过；
- 性能预算通过：12 个 JS chunks；最大 Worker 11.53 MiB；最大 App chunk 4.18 MiB；初始 Renderer 1.70 MiB；总计 22.20 MiB；
- `better-sqlite3` Node/Electron 原生绑定验证通过。

## 尚未完成

- 生产 Main composition root 尚未构造 Binding Store、Lease Store 或 Lifecycle Coordinator；
- Session create/open/delete 尚未调用 bind/unbind；
- Axis run terminal transition 和应用 shutdown 尚未调用 cleanup；
- public Session record 尚不暴露 `projectId`；
- Guarded Safe Write 没有生产 IPC 或用户可达入口；
- 未生成安装包或便携包。

不得把 0.1.40 描述为已经交付的生产安全写入或完整生命周期功能。

## 下一步

独立复审后，先接生产 Main composition root 的身份与清理生命周期，不开放真实写 IPC：

1. 启动时绑定现有 Session，新建/打开 Session 时 bind；
2. Run 终态成功提交后调用 Run cleanup；
3. Session 删除和 shutdown 调用 Session cleanup；
4. 对 cleanup 中断、重启和 TTL 兜底建立恢复测试；
5. 再单独评审生产 Guarded Safe Write 与用户可达 E2E。
