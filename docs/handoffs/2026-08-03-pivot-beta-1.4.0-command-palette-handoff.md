# Pivot Beta-1.4.0 Command Palette handoff

Date: 2026-08-03  
Display version: `Beta-1.4.0`  
Package version: `1.4.0-beta`

## Delivered engineering slice

This slice implements the current Figma Command Palette node `597:5670` as a
real production path. The current Figma page contains 81 top-level frames; the
additional Docs, Marketplace, automation, New Project, empty-state and diagram
frames were audited but are not claimed by this slice.

- `src/renderer/command-palette/command-palette-model.ts` owns the pure item
  projection, normalized filtering, selection wrapping and shortcut contract.
- `src/renderer/components/command-palette.tsx` owns the accessible dialog,
  grouped rows, Figma-aligned layout and keyboard behavior.
- The title-bar control and `Ctrl/Cmd+K` are production entry points. `Escape`
  closes, arrows move selection and `Enter` executes the selected action.
- Recent rows are projected from real active Sessions. File rows use the
  existing project-scoped Main search capability and open through the existing
  document path. Navigation commands use registered Renderer routes.
- Figma demonstration data such as `middleware/auth.ts` and auth-specific
  commands is not inserted.
- Renderer gained no new IPC channel, database handle, filesystem object,
  Admin Port or execution authority. Search is suppressed unless an active
  Session/project binding exists.
- CodeGraph impact review confirmed the change remains within the shell,
  navigation and existing file-search call chains; no concrete Main Adapter is
  imported into Renderer.

## Test-first evidence

The implementation was preceded by failing behavior and structural tests for
the missing model/component, real data projection, runtime boundary, keyboard
selection, shell reachability and production smoke contract. The production
smoke then exposed and drove a fix for React controlled-input event semantics.

Final gates:

- Vitest: 233 files / 832 tests passed.
- TypeScript strict no-emit and formal Electron build passed.
- Performance budget passed: 16 JavaScript chunks; largest worker 11.53 MiB;
  largest application chunk 4.18 MiB; initial Renderer 1.74 MiB; total output
  22.83 MiB.
- `better-sqlite3` native binding matches Electron.
- Production-build Command Palette smoke passed the button, `Escape`,
  `Ctrl+K`, query, `Enter`, close and Settings navigation path.
- Production-build Now and Settings smoke paths passed.
- No installer or portable package was generated.

## Explicit non-delivery and next work

- This is a local application command surface, not a plugin command registry,
  arbitrary shell executor or external runtime command API.
- File results remain deliberately project-scoped and unavailable without an
  active project binding.
- The current Figma additions for API Reference, Guides, Changelog, Recent,
  Shared, Bookmarks, Repositories, Snippets, Mind Map, Whiteboard, Diagrams,
  Marketplace details/updates/favorites, Create Pipeline, Run Log Detail, New
  Project and empty states are not yet production-complete.
- Marketplace install/update execution, remote catalog, signed distribution,
  packaged E2E and real previous-version upgrade/rollback remain open.

The recommended next independent Figma slice is New Project plus the related
no-project/empty states, using existing project/session capabilities first.
Automation and Marketplace screens should only advance with their own strict
shared contracts, narrow Ports and real production behavior.
