## Behavioral guarantees

- Every query is strictly validated, session-scoped and bounded to at most 100
  records.
- Renderer can request only the active session projection. It receives no
  database handle, registry, Provider Store, Admin Port or filesystem
  capability.
- The projected record includes bounded decision, finding-count, reviewer
  identity and measured-usage metadata; it excludes prompts, raw diffs, file
  contents, secrets and privileged configuration.
- Evidence and usage records are validated again after SQLite reads. Corrupt or
  ownership-inconsistent data fails closed instead of being rendered.
- Renderer validates the Main response against the same Shared contract and
  discards stale responses after session changes.
- Loading, disabled, not-configured, empty, malformed/error, populated and
  truncated result states are explicit.
- Telemetry IPC registration is isolated in a focused Main-only module and is
  covered by the repository 800-line and import-direction architecture gate.

## Important limits

- Semantic review remains explicit and default-off; this slice exposes its
  state and durable evidence but does not enable it for every Provider or user.
- Reviewer route configuration still depends on Main-owned production
  configuration rather than a complete user-manageable settings workflow.
- Provider-specific model/capability probes and broad real-provider
  qualification remain.
- Source evidence is file-and-line bounded, not yet AST/symbol-, rename- or
  column/range-aware.
- Restart/kill/partial-provider chaos campaigns, accessibility and localization
  qualification remain before a v2.0 release claim.
- The external Obsidian product package was not changed in this slice set.
