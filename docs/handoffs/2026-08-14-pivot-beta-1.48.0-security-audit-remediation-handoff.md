# Pivot Beta-1.48.0 security audit remediation handoff

Date: 2026-08-14  
Display version: `Beta-1.48.0`  
Package version: `1.48.0-beta`

## Remediated findings

1. **S-01 — deleted-session capability resurrection**
   - `SessionRegistry.getActive()` is now the only project-root lookup used by
     live IPC and Agent file capabilities.
   - A soft-deleted session can no longer be read through `session:get`, forked,
     used for file IPC, or retained through a file watcher.
   - Soft deletion aborts the Agent run, clears pending permission state,
     destroys all session terminals, closes all session file watchers, releases
     Axis leases and unbinds the Axis project before committing deletion.
   - Explicit `undo-delete` rebinds the project and is the only supported path
     back to an active session.

2. **S-02 — unbounded external CLI Agent output**
   - Main now owns immutable, validated limits for stdout, stderr, individual
     lines, unterminated buffers, event text, tool input bytes/depth, queued
     events/bytes and the aggregate Agent response.
   - Exceeding any Adapter limit clears the queue, terminates the child process,
     removes listeners and surfaces a controlled error. Aggregate response
     overflow fails before the overflowing text is emitted to Renderer.
   - Tests cover real fake-process termination for unterminated output,
     interleaved line tails, stderr, queue pressure, oversized event fields,
     nested input and aggregate response growth.

3. **S-03 — dependency advisories**
   - The five packages named by the audit are now locked to fixed releases:
     `@hono/node-server@1.19.17`, `hono@4.13.2`, `fast-uri@3.1.5`,
     `ip-address@10.5.0` and `js-yaml@4.3.1`.
   - The broader desktop/toolchain audit required major upgrades rather than a
     forced lockfile rewrite: Electron 43.4.0, electron-builder 26.15.3,
     electron-vite 5.0.0, Vite 7.3.6, Vitest 3.2.6 and React plugin 5.2.0.
   - Patched transitive releases include `postcss@8.5.26` and
     `nanoid@3.3.18`. Official full-tree `npm audit` reports zero findings.

4. **MCP dormant execution debt**
   - A structural gate now proves MCP stdio/config implementation is not
     referenced by production Main IPC, preload, shared IPC or Renderer client
     surfaces.
   - This does not declare MCP execution delivered or generally safe. Before
     production wiring, it still requires trusted configuration provenance,
     explicit approval, capability grants and an auditable allowlist.

## Architecture facts

- Session lifecycle IPC is extracted behind three narrow Main Ports: lifecycle
  registry, binding lifecycle and capability revocation.
- Renderer and Worker receive no database, filesystem, process-spawn or Admin
  Port as part of this change.
- Main IPC remains at the repository ceiling of 800 lines, while the extracted
  module is covered by the structural line/import boundary gate.
- Vite 7's initial-chunk increase was handled by a stable React vendor chunk;
  the existing performance thresholds were not weakened.
