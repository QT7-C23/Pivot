# Pivot Beta-1.2.0 Feedback local-outbox handoff

Date: 2026-08-03  
Display version: `Beta-1.2.0`  
Package version: `1.2.0-beta`

## Delivered engineering slice

1. Current Figma Settings Feedback node `577:2787`, including Feedback in the
   exact 18-entry Settings navigation.
2. Strict shared feedback submission, record, attachment metadata and discard
   contracts with runtime validation.
3. Narrow Main `FeedbackReaderPort`, `FeedbackWriterPort`,
   `FeedbackAttachmentStagingPort` and `FeedbackAttachmentDiscardPort`.
4. Versioned SQLite local outbox with real attachment BLOB persistence,
   restart recovery, idempotent submission and corruption failure behavior.
5. Typed IPC and a narrow Renderer client. Main owns the native file dialog;
   Renderer receives no selected path or file bytes.
6. Data-backed local history. Figma demonstration records are not present in
   production.

## Failure and privacy behavior

- Unsupported, missing, oversized, duplicate or already-owned attachments
  fail closed without creating a partial feedback record.
- Removing an unsubmitted attachment deletes its BLOB immediately through a
  dedicated discard capability.
- Staged attachments abandoned by an interrupted application lifetime are
  removed when the Adapter reopens.
- Persisted malformed feedback fails closed rather than being projected into
  Renderer.
- The UI says `Saved locally`; it does not claim that a server received the
  record.
