# Pivot Beta-1.43.0 Provider model probe handoff

Date: 2026-08-13

Package version: `1.43.0-beta`

## Delivered engineering slices

1. `Beta-1.39.0`: strict bounded, secret-free Shared model probe contracts.
2. `Beta-1.40.0`: Main-only narrow Probe Port and real Provider Adapter with
   endpoint/DNS trust, byte, JSON and timeout enforcement.
3. `Beta-1.41.0`: Provider-revision-aware TTL cache, concurrent request

4. `Beta-1.42.0`: trusted Main IPC registration and real ProviderStore/secret
   composition without exposing either to Renderer or Worker.
5. `Beta-1.43.0`: strict Renderer Store and Models & Providers evidence UI.

## Behavioral guarantees

- IPC requests contain only `providerId` and `forceRefresh`; endpoint, API key,
  fetch options and arbitrary URLs are rejected.
- Main resolves the stored Provider and decrypts its credential. Renderer and
  Worker receive no Provider Store, secret reader, network Port or Adapter.
- Official Providers remain bound to code-owned endpoints. Custom endpoints use
  the existing validation and DNS-pinned request path.
- Redirects, non-200 responses, missing/non-JSON Content-Type, invalid UTF-8,
  malformed JSON, invalid model IDs and oversized payloads fail closed.
- The timeout remains active through streaming body reads and cancels a stalled
  body rather than waiting indefinitely.
- Concurrent reads of one Provider revision share one probe. Cache TTL is five
  minutes; a Provider revision change invalidates the result immediately.
- Refresh failure may return an explicitly `stale` prior success, but an initial
  failure cannot create cache evidence.
- Renderer validates every response and cross-checks `providerId`, rejects
  privileged sibling fields and ignores superseded same-Provider requests.
- The UI distinguishes not probed, loading, not configured, failure, empty,
  cached/stale, populated and truncated states.

## Important limits

- Provider-reported model listing is availability evidence only. It does not
  certify structured output, Reviewer schema compliance, context limits, cost
  or production fitness.
- Semantic review remains default-off and its route is still primarily
  Main-owned production configuration rather than a complete durable settings
  workflow.
- Model probe cache is intentionally in-memory; restart performs a new probe.
- Broad real-Provider qualification, restart/kill/partial-response chaos,
  accessibility and four-locale content qualification remain.
- The external Obsidian product package was not changed in this slice set.
