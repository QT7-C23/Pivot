# Pivot Beta-0.1.64 child-Run replan task scheduling handoff

Date: 2026-08-02  
Visible version: `Beta-0.1.64`  
Package/updater SemVer: `0.1.64-beta`

## Completed slice

Beta-0.1.64 adds strict shared replan next-Task schedule evidence, narrow Main
Ports, a WAL SQLite Registry, a decision-only scheduler, a frozen Shadow Run
reader Port and production Main lifecycle composition.

The schedule identity is `(decisionId, childStateRevision)`, not decision-only,
so one committed replan can safely advance a multi-Task child DAG after each
authoritative Run-state transition. The scheduler derives the first
dependency-ready pending Task from the persisted child plan/state and accepts
only exact `fs.safeWrite` Tasks.

## Important non-capability

The registered Dry-run failure source still emits authentic `minor` evidence
and therefore selects retry, not replan. Beta-0.1.64 does not relabel that
failure, invoke this scheduler from the registered handler, generate a child
proposal or submit Guarded Safe Write. There is no Pivot IPC/Preload/Renderer
surface. This remains a production-composed bottom-layer capability.
