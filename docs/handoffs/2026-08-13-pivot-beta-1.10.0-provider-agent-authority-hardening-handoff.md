# Pivot Beta-1.10.0 Provider and ordinary-Agent authority hardening handoff

Date: 2026-08-13  
Display version: `Beta-1.10.0`  
Package version: `1.10.0-beta`

## Delivered engineering slice

- Added a Main-owned Provider trust policy. Built-in kinds use exact official
  endpoints; custom endpoints allow remote HTTPS or loopback HTTP and reject
  credentials, query/fragment data, private/link-local/reserved IP literals
  and known metadata hostnames.
- Endpoint changes cannot reuse an already stored secret: the caller must
  provide a new API key, and a rejected change leaves the original endpoint and
  key untouched.
- Provider connection tests and AI SDK requests are bound to the configured
  origin and API path with redirects disabled, preventing credential forwarding
  across redirect or request-target changes.
- `allow_session` now authorizes the exact normalized tool input. A different
  command, arguments, working directory or file mutation prompts again.
- `CommandRunner` now passes only an explicit non-secret environment allowlist
  to subprocesses. Shell execution remains disabled and existing timeout/output
  bounds remain enforced.
- `DefaultAgentToolExecutor` depends on narrow command and file-mutation Ports.
  Production ordinary-Agent file mutation is wired to a fail-closed Adapter;
  it cannot reach the legacy `SafeFileWriter`. Manual editor saving remains on
  its separate trusted IPC path.

## Verification evidence

## Explicit limitations

- Ordinary Agent `fs.safeWrite` is intentionally unavailable in production
  until a reviewed proposal/review/execution Adapter is integrated with Axis
  Guarded Safe Write. This is a fail-closed hardening state, not delivered
  automatic Agent editing.
- Manual editor saves still use the existing trusted Renderer-to-Main path and
  are not represented as Agent execution authority.
- Custom Provider hostname DNS pinning is not implemented. Exact origin/path,
  TLS scheme, static network classification and redirect rejection are enforced;
  a future transport slice may add resolver/pinned-connect evidence.
- Marketplace projection, Favorites IPC/UI, package verification, sandboxed
  installation/execution and signed external release work remain outstanding.
