# Pivot Beta-0.1.60 production Dynamic Pivot runtime handoff

Date: 2026-07-30  
Visible version: `Beta-0.1.60`  
Package/updater SemVer: `0.1.60-beta`

## Completed slice

- Added a default-off, strict Main feature gate for Dynamic Pivot.
- Added durable dispatch-result persistence and strict restart parsing.
- Constructed the Pivot coordinator, replan coordinator, dispatcher and all
  seven concrete action handlers in one production Main runtime.
- Wired the runtime into application readiness, Session deletion and
  idempotent shutdown.
- Added startup recovery that consumes committed decisions without a durable
  dispatch result.
- Added durable Worker-attempt/self-repair evidence ownership and cleanup.
- Rejected valid same-route action output when it does not match the exact
  committed action.

## Invariants preserved

- Disabled mode constructs no Pivot registry and invokes no Provider/model or
  planner factory.
- Concrete adapters are application-root owned and consumers receive only
  narrow Ports.
- Worker and Renderer receive no dispatcher, Admin Port, SQLite handle,
  signing material or filesystem capability.
- No Pivot IPC, Preload contract or UI surface was added.
- Every dispatch result is bound to the committed action, decision, revision,
  Run and Session before persistence or reuse.

## Deliberately absent

- a production Run/Dry-run trigger that calls `decideAndDispatch` for newly
  observed failures;

- stop-driven external process interruption or Lease cleanup;
- Human Escalation notification, queue or UI lifecycle;
- Pivot IPC, Preload, Renderer or UI reachability.
