# Pivot Beta-1.12.0 Renderer terminal authority handoff

Date: 2026-08-13  
Display version: `Beta-1.12.0`  
Package version: `1.12.0-beta`

## Delivered engineering slice

- Removed the unused programmatic `term:run` Renderer IPC capability from the
  shared contract, strict validator, Main handler and Renderer service.
- Kept Main-only `AgentCommandRunPort` and Axis Gate command capabilities
  independent from Renderer IPC.
- Made PTY creation require a Main-supplied owner ID.
- Required the same Electron `webContents.id` for every subsequent write,
  resize and destroy operation.
- Returned the same `Terminal unavailable` failure for missing and foreign
  terminal IDs, avoiding an ownership/existence oracle.
- Preserved owner-scoped cleanup when a Renderer closes.

## Verification evidence

- A new structural test prevents reintroducing `term:run` or a structured
  `CommandRunResult` into Renderer IPC while preserving the explicit
  interactive terminal contract.
- A real TerminalManager failure-path test proves a foreign Renderer cannot
  write, resize or destroy another owner's PTY.
- Targeted IPC, terminal, Agent command and Axis Gate regressions pass.
- Full regression passed: 257 test files / 940 tests.
- Strict TypeScript and the formal Electron production build passed. Main is
  762.30 kB.
- Performance passed: 20 JavaScript chunks, largest worker 11.53 MiB, largest
  application chunk 4.18 MiB, initial Renderer 1.74 MiB and total 22.90 MiB.
- Both Node and Electron native dependency gates report matching bindings.
- No installer or portable package was generated.

## Explicit limitations

- The interactive terminal intentionally lets its owning Renderer send input
  to its own PTY. This hardening is owner isolation, not a claim that Renderer
  compromise has no command-execution consequence.
- Ordinary Agent file mutation remains fail-closed pending a reviewed
  Agent-to-Axis Guarded proposal boundary.
- Marketplace projection/Favorites UI, package verification, sandboxed plugin
  execution and signed external-release drills remain outstanding.
