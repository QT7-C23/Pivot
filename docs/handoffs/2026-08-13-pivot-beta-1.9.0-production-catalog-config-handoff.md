# Pivot Beta-1.9.0 production Catalog configuration handoff

Date: 2026-08-13  
Display version: `Beta-1.9.0`  
Package version: `1.9.0-beta`

## Delivered engineering slice

- Added a strict Main-only parser for
  `PIVOT_MARKETPLACE_CATALOG_CONFIG`.
- The bounded JSON object requires `schemaVersion: 1`, one strict Marketplace
  Catalog Source and one public Ed25519 SPKI PEM key.
- Unknown fields, partial configuration, malformed JSON, invalid algorithms,
  non-Ed25519 keys, private-key material, credential-bearing URLs and URL
  fragments fail before any Catalog composition.
- Wired the configuration into the production Main composition root and its
  idempotent shutdown lifecycle.
- Preserved the default-off invariant: when the variable is unset, no Catalog
  SQLite file or network Transport is constructed.
- Proved the configured path with a real Ed25519-signed snapshot through the
  existing bounded HTTPS Transport, verified Reader and durable cache.

## Verification evidence

- Targeted configuration/composition/transport/trust coverage: 6 test files / 34 tests
  passed.
- Full regression: 251 test files / 912 tests passed.
- Strict TypeScript and the formal Electron production build passed.
- Performance budget passed with 20 JavaScript chunks, 11.53 MiB largest
  worker, 4.18 MiB largest app chunk, 1.74 MiB initial Renderer and 22.89 MiB
  total JavaScript.
- `better-sqlite3` native bindings match both Node and Electron.
- No installer or portable package was generated.

## Explicit limitations

- Pivot ships no official Catalog HTTPS URL or public key. Production remains
  unconfigured unless an operator supplies the complete trusted configuration.
- No configuration field enters shared IPC, Preload or Renderer code.
- No Catalog/Favorites IPC or Renderer projection exists.
- Package-byte verification, archive extraction, sandboxed installation,
  activation, update, rollback, uninstall and publish CLI remain absent.
