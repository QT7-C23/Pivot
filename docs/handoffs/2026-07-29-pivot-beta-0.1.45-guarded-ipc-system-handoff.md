## Delivered engineering slice

Beta-0.1.45 verifies the default-off Guarded Safe Write chain at the registered Main IPC-handler boundary. The system suite uses the real composition root, shared request validation, trusted-sender check, SQLite stores, filesystem adapters, permission signal path, transaction recovery and durable Run state.

This slice does not add a user-facing action. The existing Renderer service/store action still has no screen or automatic planner caller, and the runtime still requires `PIVOT_AXIS_REAL_EXECUTION=1`.

## Main-only test boundary

`IpcHandlerOptions.axisGuarded` accepts an optional `AxisGuardedIpcInfrastructure`:

- `AxisGateCommandRunPort`;
- `AxisLeaseLifecyclePort`;
- a permission timeout value.

These inputs exist only at the Main composition root. They are not shared IPC fields, and neither Renderer nor Worker receives a Registry, Admin Port, SQLite handle, filesystem adapter, proof secret or Gate command capability.

Production defaults remain unchanged: Main constructs the concrete command runner, Lease lifecycle and standard permission timeout.

## Test-first evidence

The structural test first failed because the narrow Main infrastructure seam did not exist. After implementation, the registered-handler system tests prove:

1. an untrusted frame is rejected before request handling;
2. a forged `projectRoot` is rejected by strict shared validation before Run-state mutation;
3. a real `permission:request` → `chat:permission` denial roundtrip blocks without writing and durably fails the Run;
4. permission timeout creates no Checkpoint or write;
5. an injected failing Gate physically restores the Checkpoint and records failed state;
6. an interrupted `worker-started` transaction is rolled back before the guarded handler proceeds;
7. injected Lease cleanup failure rejects the IPC call after failed state is durably committed.

The runtime resource owner now closes every SQLite store it constructs. Close is idempotent and preserves lifecycle shutdown ordering.
