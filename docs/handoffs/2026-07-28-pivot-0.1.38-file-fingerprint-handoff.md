# Pivot 0.1.38 External File Fingerprint Evidence 交接

## 本轮完成

完成 External File Fingerprint Evidence 独立底层切片，尚未接入生产 Guarded Safe Write：

- 严格区分存在文件与缺失目标的共享合同；
- 证据绑定 project/run/session/task、稳定 file key 和项目相对路径；
- Task Port 仅暴露 `captureAll` 与 `verifyAll`；
- Main Adapter 负责权威项目路径、流式内容 SHA-256 和文件实例摘要；
- Main-owned HMAC-SHA-256 proof 防止 Worker 篡改证据；
- 最多 128 个目标，等价 file key 去重，稳定路径排序；
- verifyAll 区分 modified、deleted、created、replaced 与 stale；
- 跨 Task、proof 篡改、路径逃逸、目录、未知 Session 和读取期间变化均失败关闭。
