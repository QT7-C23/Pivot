# Pivot Beta-1.7.0 trusted Catalog Reader handoff

Date: 2026-08-11  
Display version: `Beta-1.7.0`  
Package version: `1.7.0-beta`

## Delivered engineering slice

- Added the canonical unsigned Catalog payload schema and serializer in
  `src/shared/marketplace-contracts.ts`.
- Added narrow Transport, Trust Reader and Catalog Cache Reader/Writer Ports.
- Added a Main-only Ed25519 trust registry that rejects duplicate sources,
  malformed public keys and non-Ed25519 keys.
- Added `VerifiedMarketplaceCatalogAdapter` behind the existing Catalog Reader
  Port. It verifies trusted source binding, real Ed25519 signatures, time and
  monotonic revision before committing cache state.
- Added a versioned SQLite cache with restart recovery, row validation,
  downgrade rejection and same-revision equivocation rejection.
- Offline fallback occurs only after transport failure and only while cached
  evidence is still strictly valid.

## Verification evidence

- Targeted Marketplace coverage: 6 test files / 27 tests passed.
- Full Vitest regression: 245 test files / 883 tests passed.
- Strict TypeScript no-emit and the formal Electron build passed.
- Performance remained within the unchanged gate: 20 JavaScript chunks,
  largest worker 11.53 MiB, largest app 4.18 MiB, initial Renderer 1.74 MiB
  and total output 22.86 MiB.
- `better-sqlite3` native binding matches Electron.
- No installer or portable package was generated.

## Explicit limitations

- There is no concrete production HTTP Transport Adapter or configured Catalog
  URL/public key in the application composition root.
- There is no Marketplace IPC, Renderer service/store or production Figma
  Favorites data wiring.
- Package signatures are declared but package bytes are not downloaded or
  verified in this slice.
- There is no archive extraction, installation, activation, rollback, update
  or uninstall lifecycle.
