# Pivot Beta-1.11.0 Provider DNS pinning handoff

Date: 2026-08-13  
Display version: `Beta-1.11.0`  
Package version: `1.11.0-beta`

## Delivered engineering slice

- Added narrow Main-only `ProviderDnsResolutionPort` and
  `ProviderPinnedRequestPort` capabilities.
- Added a Node DNS Adapter and Undici request Adapter. A request resolves its
  exact configured hostname once, validates every returned address, freezes
  the approved set and supplies a lookup function that cannot resolve or select
  anything outside that set.
- Mixed public/private DNS responses fail closed; Pivot never selects only the
  public-looking answer from a suspicious response.
- The pinned lookup verifies the hostname again and supports both single-address
  and `all` lookup shapes without calling system DNS a second time.
- TLS requests retain the configured URL hostname for certificate validation
  and SNI. Redirects and origin/API-path escape remain disabled by the prior
  Provider trust policy.
- Production defaults now cover connection testing, Agent conversation, Axis
  planning, Dynamic Pivot and Guarded proposal generation.

## Verification evidence

- Provider network security coverage includes private, mixed-answer, immutable
  binding, origin escape and a real loopback socket path.
- Full regression: 256 test files / 937 tests passed.
- Strict TypeScript and the formal Electron production build passed.
- Performance and Node/Electron native dependency gates passed.
- No installer or portable package was generated.

## Explicit limitations

- This is per-request DNS evidence and connection pinning. It intentionally
  does not add a shared DNS cache whose stale lifetime could outlive network
  changes.
- Custom loopback HTTP remains supported for explicitly local model servers;
  non-loopback custom Providers require HTTPS.
- Ordinary Agent `fs.safeWrite` remains fail-closed until an explicit reviewed
  Agent-to-Axis Guarded proposal Adapter is designed and integrated.
- Marketplace projection/Favorites UI, package verification, sandboxed plugin
  installation/execution and signed external-release drills remain outstanding.

## Explicit next work

2. Design and test the ordinary-Agent-to-Axis reviewed proposal Port before

3. Continue the Marketplace read-only projection and strict IPC slice.
