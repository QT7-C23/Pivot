## Completed slice

Beta-0.1.65 adds strict post-retry `direction` failure evidence and connects a
real failed Guarded retry to committed replan, child-Run scheduling, reviewed
proposal generation and Guarded child completion. The new orchestration uses a
per-schedule identity so a multi-Task child DAG is not collapsed into one
decision-unique record.

The persistence layer fails interrupted preparation/submission to
`recovery-required`. Main owns construction, readiness, Session cleanup and
shutdown. Only narrow Ports cross boundaries.

## Important limits

The registered path advances one scheduled child Task. It does not yet loop
through a multi-Task child DAG, schedule self-repair/Fixer assignments, expose
autonomous Pivot UI, or provide one unified restart-queryable history view.
Those remain release work and must not be described as shipped functionality.

## Next recommended slice

Build a durable continuation driver that advances the next dependency-ready
Task only after authoritative child Run-state completion, and adds a stable
completion/failure history projection. Keep self-repair/Fixer scheduling and
release-process qualification as separate reviewed slices.
