# Pivot Beta-0.1.55 UI V2 shell and Now dashboard handoff

Date: 2026-07-30  
Visible version: `Beta-0.1.55`  
Package/updater SemVer: `0.1.55-beta`

## 1. Delivered engineering slice

Beta-0.1.55 adapts the Pivot UI V2 Figma visual system into the existing production Renderer without importing stale product semantics.

1. `PivotAppShell` now renders one stable route rail on every page.
2. Settings can no longer hide Work/Artifacts or duplicate Extensions under Market/Ext aliases.
3. Now uses real Session and `WorkItemSnapshot` data for four summary cards and its Continue, Attention, Run and Artifact surfaces.
4. The dashboard follows the Figma `44px` titlebar, `52px` rail, warm neutral palette, compact typography and two-column content hierarchy.
5. At narrower widths the activity panel collapses first, then context; the dashboard and summary cards collapse independently.
6. Existing Project, Work, Artifact, Automations, Extensions and Settings routes remain production-owned and reachable.

No Main, Worker, IPC, database, Lease, Fingerprint, Checkpoint, Permission or Execution Authority boundary changed.

## 2. Explicit non-delivery

- This is not completion of every Figma frame.
- No installer or portable package was generated.
