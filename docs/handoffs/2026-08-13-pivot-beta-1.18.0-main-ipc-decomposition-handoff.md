## Important limits

- This is a boundary-preserving refactor, not a newly user-reachable feature.
- The composition function still owns many IPC feature groups. Future splits
  should use narrow registration Ports/dependency objects, not a universal
  service container or Admin object.
- Semantic Reviewer Gate 2/3 and its untrusted-output validation, evidence,
  escalation and recovery path remain the next major Axis capability gap.
