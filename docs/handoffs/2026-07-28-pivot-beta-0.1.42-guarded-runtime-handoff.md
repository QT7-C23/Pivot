# Pivot Beta-0.1.42 Production Guarded Runtime 交接

## 本轮完成

- 显示版本改为 `Beta-0.1.42`，npm/Electron/updater SemVer 使用 `0.1.42-beta`；
- 新增严格 `PIVOT_AXIS_REAL_EXECUTION=0|1` 解析，默认关闭且关闭时不构造 guarded runtime 资源；
- 新增 production-only runtime factory，在 Main 内组合 Binding、Lease、Fingerprint、Checkpoint、Authority、Transaction、Rollback、Gate、Blackboard Evidence 与窄 Worker；
- 与 Agent Runtime 共享 Main-owned `PermissionManager`，仅通过 `AxisPermissionManagerPort` 依赖；
- Gate 通过后、Transaction complete 前写入 `axis.safe-write.precommit` Blackboard Evidence；
- Blackboard Evidence 写入失败会进入既有物理回滚，不能形成假完成；
- startup readiness 等待持久事务恢复；
- Session hard delete 与 runtime close 清理其拥有的 Blackboard、Gate Evidence、Transaction 资源；
- 修复 Windows 8.3 短路径与 canonical path 不一致造成的恢复误报越界；
- 未增加任何真实写 IPC、Preload 或 Renderer 能力。

## 测试与门禁

- 新增测试先因 runtime factory、会话级 Blackboard cleanup 与 precommit evidence 缺失而失败；
- 真实恢复测试随后暴露 Windows 短路径 rollback defect，并先保持红灯后修复；
- 定向 6 个测试文件、31 项通过；
- 全量 127 个测试文件、504 项测试全部通过；
- TypeScript `tsc --noEmit` 通过；
- Electron production build 通过；
- 性能预算通过：12 个 JS chunks；最大 Worker 11.53 MiB；最大 App chunk 4.18 MiB；初始 Renderer 1.70 MiB；总计 22.30 MiB；
- `better-sqlite3` Electron 原生绑定验证通过；
- 未生成安装包或便携包。

## 真实失败与恢复证据

- Blackboard storage error 发生在 Gate 通过后，现有文件恢复原内容、新文件被删除、Transaction 进入 `rolled-back`、Lease 释放；
- 重启前持久化 `worker-started` Transaction，runtime `ready` 前自动物理回滚并进入 `rolled-back`；
- Windows 短路径 receipt 会先经权威 root resolver 规范化后执行删除，同时 terminal evidence 仍精确覆盖原 receipt；
- feature 未设置或为 `0` 时，传入不可访问依赖也不会被 factory 读取或构造；
- feature 非 `0|1` 直接失败，不能用模糊 truthy 值打开。

## 尚未完成

- 无用户可达的 Axis 真实写合同、IPC 或界面；
- 无生产用户流的 modified/deleted/created/replaced 外部变化 E2E；
- Blackboard 尚无 completion/failure evidence 投影与用户界面；
- Gate 命令仍是 Main 固定 compile/test，尚无可信项目级 profile discovery；
- Dynamic Pivot repair/retry/replan/Fixer/discard/escalation handlers 未接入；
- public Session contract 仍不暴露 `projectId`；
- 无后台 Lease heartbeat；
- 未生成安装包或便携包。

不得把 Beta-0.1.42 描述为已经交付用户可用的生产安全写入。它是默认关闭、无公开入口的生产 Main 底层组合与恢复切片。

## 下一步与 1.0 估算

下一切片应在单独复审后建立最窄的用户可达 execution contract，并补外部变化、回滚、恢复与 cleanup failure 的真实 E2E；不得把 Admin Port、数据库句柄、Fingerprint proof secret 或原始文件系统能力放进 IPC。

当前 v1.0 internal beta 工程估算约完成 82%，按当前小切片节奏约还需 10–17 个独立工程切片。主要剩余项是用户可达 guarded execution、Dynamic Pivot action handlers、Role/兼容适配、模型路由与降级、Gate 3/可信 Gate profile、Unified Work Model 收口、引擎 soak/E2E 和签名升级/回滚发布演练。
