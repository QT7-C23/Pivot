# Pivot Beta-1.8.0 bounded Catalog Transport handoff

Date: 2026-08-11  
Display version: `Beta-1.8.0`  
Package version: `1.8.0-beta`

## Delivered engineering slice

- Added `BoundedHttpsJsonTransportAdapter` behind
  `MarketplaceCatalogTransportPort`.
- HTTPS requests omit credentials, use manual redirect handling and accept no
  URL credentials or fragments.
- Redirects, non-200 responses, missing/wrong JSON media types, oversized
  declared bodies, oversized streaming bodies, invalid UTF-8 and malformed
  JSON fail closed.
- One bounded `AbortController` timeout remains active for both connection and
  response-body consumption.
- Added `createMarketplaceCatalogRuntime`, which composes the concrete
  Transport, Trust Registry, verified Reader and SQLite cache only when a
  trusted source is explicitly configured.
- Proved a complete deterministic online verification and restart/offline
  recovery path with real Ed25519 signatures and real streamed `Response`
  values.

## Verification evidence

- Targeted Transport/composition coverage: 3 test files / 13 tests passed.
- Full regression: 248 test files / 896 tests passed.
- Strict TypeScript no-emit and the formal Electron production build passed.
- Performance budget passed unchanged: 20 JavaScript chunks, largest worker
  11.53 MiB, largest application chunk 4.18 MiB, initial Renderer 1.74 MiB and
  total output 22.86 MiB.
- `better-sqlite3` native binding matches the Electron runtime.
- No installer or portable package was generated.

## Explicit limitations

- No official Catalog HTTPS URL or Ed25519 public key is configured in the
  application composition root.
- The runtime factory remains absent/default-off unless explicit trusted
  configuration is supplied by its owner.
- There is no Marketplace IPC, Renderer service/store or production Figma
  Favorites data wiring.
- There is no package-byte verification, archive extraction, installation,
  activation, rollback, update or uninstall lifecycle.

## Explicit next work

1. Define strict production source configuration loading without accepting a
   private key, secret or Renderer-selected trust root.
2. Keep an honest unavailable state until the product owner provides the real
   HTTPS Catalog URL and Ed25519 public key.
3. Add read-only verified Catalog/Favorite projection IPC, then a separate
   optimistic Favorite write IPC, before implementing the Figma Favorites
