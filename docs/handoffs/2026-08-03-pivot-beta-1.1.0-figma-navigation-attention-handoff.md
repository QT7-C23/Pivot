# Pivot Beta-1.1.0 Figma navigation and Attention handoff

Date: 2026-08-03  
Display version: `Beta-1.1.0`  
Package version: `1.1.0-beta`

## Delivered engineering slice

1. Current global Rail from Figma Core Screens: Avatar, Home, Projects, Auto,
   Docs, Market, Ext, Settings and Help.
2. Typed `docs`, `marketplace` and `help` application routes while retaining
   internal Sessions, Work, Artifacts and Runtimes routes.
3. Docs & Files page backed by the existing immutable Renderer file-tree
   projection and existing project-scoped open-file callback.
4. Searchable Help page whose cards navigate to actual Docs and Settings
   destinations.
5. Separate Marketplace and Extensions presentation modes backed only by
   configured provider/resource data; no price, entitlement or fake catalog.
6. Additional Interfaces Attention projection from actual aggregate runtime
   error state and strict shared `PermissionRequest` values. The persistent
   panel can be dismissed and reopened from its queue entry.

## Boundaries retained

- Renderer receives no Admin Port, database handle, filesystem object or Main
  implementation import.
- Docs consumes supplied `FileTreeEntry` values and callbacks only.
- Attention consumes supplied strings and `PermissionRequest` values only; it
  neither reads global infrastructure nor invents demonstration events.
- No installer or portable package was generated.
