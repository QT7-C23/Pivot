Date: 2026-07-30  
Visible version: `Beta-0.1.57`

## Completed slice

- Added strict shared Human Escalation create/receipt contracts.
- Added strict four-field Pivot `escalate` request and cross-validated result.
- Added a frozen `AxisHumanEscalationPort`.
- Added an independent WAL-mode SQLite Registry with one receipt per decision.
- Added a Main-only Pivot escalation Handler that derives all attention
  evidence from the committed decision and trigger.
- Covered failed task-bound security escalation and paused taskless design
  escalation.
- Covered sequential idempotency, matching concurrency recovery, restart
  recovery, malformed evidence, ownership, revision, event, snapshot, usage,
  category, and forced-decision failures.

## Invariants preserved

- The Handler depends on Ports, not concrete Registry implementations.
- Worker and Renderer receive no Admin Port, database, filesystem, command,
  Lease, Fingerprint, Checkpoint, or Execution Authority capability.
- Opening attention does not mutate Run state, schedule work, invoke a Worker,
  or notify a person.
- The foundation is outside production composition, IPC, and UI.
- Existing Dynamic Pivot continuation and discard foundations are unchanged.
