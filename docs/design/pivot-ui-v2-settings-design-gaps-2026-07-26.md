# Pivot UI V2 — Settings 设计待补清单

审查日期：2026-07-26  
设计基准：Pivot UI V2 / `07 Core Screens` / Settings 系列画板  
原则：实现以 Figma 为准。以下内容没有自行补画进现有 Settings，等待后续设计确认。

## 连接与 Provider

1. 新建、自定义、编辑连接的完整表单与校验状态。
2. API Key / OAuth 凭据录入、替换、撤销和安全提示弹窗。
3. 删除连接、移除密钥、禁用连接的确认弹窗与撤销反馈。
4. Provider 列表为空、搜索无结果、加载失败和无权限状态。
5. Monitor 的加载、空数据、请求失败和历史指标视图。

## Runtime 与 CLI

1. Codex CLI、Claude Code CLI 等编码器的独立配置与切换界面。
2. CLI 未安装、PATH 未发现、手动选择可执行文件和重新扫描流程。
3. CLI 版本检测、更新、修复、执行中、成功和失败状态。
4. Pivot Engine 与外部 CLI 的同级关系及各自详情页。

## 更新

1. 发现新版本后的版本详情。
2. 下载进度、暂停、重试、校验失败和离线状态。
3. 下载完成后的“重启并安装”与安装失败状态。
4. 自动更新策略发生冲突或被系统策略禁止时的反馈。

## 扩展与数据管理

1. Skill、Plugin、MCP、Slash Command 的安装、添加、编辑、移除和详情弹窗。
2. Runtime、Registry、Model Source、MCP Server 的添加与编辑表单。
3. 文件夹选择器、路径不可写、空间不足和迁移进度状态。
4. 导出、清理、重置、删除全部数据的确认、进度、成功和失败反馈。

## 全局状态与适配

1. Command Palette 展开、搜索、无结果和命令执行状态。
2. Settings 的窄窗口与最小窗口宽度布局。
3. 深色主题下的完整 Settings 画板，而不只是主题预览卡。
4. 中文及其他语言的文字增长、截断和换行规范。
5. Windows、macOS、Linux 的快捷键差异。
6. About 页面链接的目标、不可用状态和外部跳转确认。
7. 通用加载、空状态、错误、离线、成功 Toast 与长任务进度规范。
